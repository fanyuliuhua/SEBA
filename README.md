## Introduction
Protein remote homology alignment remains a challenging problem in bioinformatics, particularly in low-identity settings where weak evolutionary signals often limit the reliability 
of conventional sequence-based methods. Recent protein language model–based approaches have improved sequence-only alignment by introducing embedding-derived residue similarity matrices, 
but these matrices can still be affected by score bias, local noise, and fragmented matching patterns, thereby constraining alignment quality.

In this study, we present SEBA (Smoothed Embedding-Based Alignment), an unsupervised sequence-only framework designed to refine residue-level similarity estimation for remote homology alignment. SEBA combines bidirectional Z-score normalization with alignment-aware diagonal smoothing to refine embedding-derived similarity matrices by reducing score bias, suppressing isolated noisy responses, and enhancing locally continuous homologous signals before dynamic programming. Evaluations across multiple benchmarks show that SEBA improves alignment performance over existing sequence-only baselines while preserving sensitivity to structural similarity. Thus, SEBA provides an effective and computationally simple refinement strategy for embedding-based alignment in sequence-only remote homology analysis.

Benchmark evaluations demonstrate consistent improvements in residue-level alignment accuracy across multiple datasets.Using ProstT5 embeddings, SEBA achieves F1-scores of **0.289, 0.700, and 0.514 ** on **MALISAM, MALIDUP, and SABMark**, respectively, corresponding to relative improvements of **17.3%, 12.0%, and 7.3%** over EBA with the same language model .On **BAliBASE**, SEBA achieves the highest SP-scores across all five evaluated subsets, outperforming **PEBA_ProtT5** by **10.2%, 3.1%, 4.3%, 1.9%, and 0.4%** on RV11, RV12, RV911, RV912, and RV913, respectively. On **HOMSTRAD**, SEBA reaches an F1-score of **0.881**, outperforming EBA and Foldseek by **2.4% and 3.6%**, respectively.

## Quick Start
A simple example is provided for running SEBA on a pair of protein sequences with precomputed residue embeddings. Sample data are available in ../data/, including SeqA.json, SeqB.json, SeqA_Emb.json, and SeqB_Emb.json. SeqA.json and SeqB.json contain the two input protein sequences in JSON format, with each sequence represented as a string. SeqA_Emb.json and SeqB_Emb.json contain the corresponding residue-level embeddings generated by the ProstT5 model, represented as two-dimensional arrays with one embedding vector for each residue. The example code for loading these data and running SEBA can be found in /seba/example.py.
```
import methods
import numpy as np
from utils import json_load,build_similarity_matrix

gap_open_penalty=0
gap_extend_penalty=0

seqA=json_load("../data/SeqA.json")
seqB=json_load("../data/SeqB.json")
seqA_emb=json_load("../data/SeqA_Emb.json")
seqB_emb=json_load("../data/SeqB_Emb.json")

seqA_emb=np.array(seqA_emb)
seqB_emb=np.array(seqB_emb)

similarity=build_similarity_matrix(seqA_emb,seqB_emb)
results=methods.compute_seba(similarity,gap_open_penalty=gap_open_penalty,gap_extend_penalty=gap_extend_penalty,extensive_output=True)

print(seqA)
print(results['aln_1'])
print(seqB)
print(results['aln_2'])
```
## Input and Output
### Input
SEBA requires two protein sequences and their corresponding residue-level embeddings.
#### Protein sequences
`SeqA.json` and `SeqB.json` contain the input protein sequences. Each file is stored as a JSON array containing one amino acid sequence string.
Example:
```json
[
  "TLKGQCIAEFLGTGLLIFFGVG..."
]
```
### Output

SEBA returns the alignment result as a Python dictionary. The residue correspondences for the two sequences are stored in:

- `results['aln_1']`: alignment indices for sequence A.
- `results['aln_2']`: alignment indices for sequence B.

Both arrays have the same length and jointly define the pairwise alignment. Residue indices are **0-based**, and `-1` represents a gap introduced during alignment.

For example:

```text
aln_1 = [-1, -1, 0, 1, 2, 3, 4, ...]
aln_2 = [ 0,  1, 2, 3, 4, 5, 6, ...]
```

At each alignment position:

- Two non-negative indices indicate an aligned residue pair.
- An index of `-1` indicates a gap in the corresponding sequence.

The alignment results can be inspected using:

```python
print(seqA)
print(results['aln_1'])
print(seqB)
print(results['aln_2'])
```
## Benchmark Datasets

SEBA was evaluated on six benchmark datasets covering remote-homology alignment, structure-related similarity assessment, and reference-alignment evaluation.

| Dataset | Description | Source |
| --- | --- | --- |
| **MALIDUP** | A manually curated benchmark containing 241 pairwise structural alignments of remote homologous duplicated domains. | http://prodata.swmed.edu/malidup |
| **MALISAM** | A manually curated benchmark containing 130 pairwise alignments with substantial structural divergence and challenging near-analogy cases. | http://prodata.swmed.edu/malisam |
| **SABMark** | A structure-based sequence-alignment benchmark covering diverse protein folds and difficult low-similarity protein pairs. The pairwise benchmark used in this study contains 8,952 protein pairs. | https://www.drive5.com/bench/ |
| **PISCES-derived** | A structural-similarity benchmark adopted from EBA. It contains 19,599 protein pairs with known structures, with a maximum pairwise sequence identity of 30% and a minimum chain length of 75 residues. | https://git.scicore.unibas.ch/schwede/eba_benchmark |
| **HOMSTRAD** | An expert-curated database of structure-based alignments for homologous protein families. Following the EBA benchmark setting, 1,032 representative protein pairs were used. | https://git.scicore.unibas.ch/schwede/eba_benchmark |
| **BAliBASE** | A reference multiple-sequence-alignment benchmark. Following the PEBA setting, five RV subsets (RV11, RV12, RV911, RV912, and RV913) were used, yielding 12,444 pairwise alignments. | https://github.com/mgtools/PEbA |
